    setAlphaFromPercentage

    • setAlphaFromPercentage(alpha: number): this

      Set the optional alpha component of the RGB object with a percentage value, expressed as a floating-point number between 0 and 1, inclusive.

      Parameters

      • alpha: number

        The alpha component percentage. This value must be expressed as a floating-point number between 0 and 1, inclusive. The given value will be multiplied by maxRGBValue, then passed to RGBBuilder.setAlpha, where it will be constrained then floored to the nearest integer.

      Returns this

      • The current instance of the RGBBuilder for method chaining.

      See

      RGBBuilder.setAlpha

      Throws

      • When the given value is not a finite number or within the range of [0-1].
